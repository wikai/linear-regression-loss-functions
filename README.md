# linear-regression-loss-functions
Comparison of MSE, MAE and Huber loss under outliers
# Исследование устойчивости линейной регрессии к выбросам

Программные материалы для исследования «Исследование свойств функций потерь и их влияния на устойчивость моделей линейной регрессии».

## Содержание

- `experiment.py` — компактная версия с вложенными циклами.
- `requirements.txt` — используемые библиотеки Python.

## Методика

- 100 равномерных значений x от 0 до 10; исходная зависимость y = 2x + 3.
- Нормальный шум со стандартным отклонением 1; 20 значений seed (42–61).
- 0 %, 1 %, 5 %, 10 %, 20 % наблюдений с добавленным отклонением +15 по фиксированным индексам.
- Три метода: LinearRegression (MSE), QuantileRegressor с quantile=0.5, alpha=0 (MAE), HuberRegressor с alpha=0 (Huber).
- Общая метрика E: средняя абсолютная разность предсказания и истинной прямой на заданных x.
- Для каждой модели вычисляются среднее E и выборочное стандартное отклонение по 20 повторениям.

## Запуск

```bash
python -m pip install -r requirements.txt
python experiment.py
```

Программы сохраняют CSV-таблицы и PNG-графики в папки с результатами рядом с соответствующим скриптом. Данные являются синтетическими; выводы относятся к заданным условиям эксперимента.
